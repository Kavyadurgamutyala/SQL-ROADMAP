INTERVIEW QUESTIONS

1. What is a Database?

A database is an organized collection of data used to store and manage information efficiently.

2. What is a Table?

A table is a collection of related data stored in rows and columns.

3. What is a Row?

A row represents a single record in a table.

4. What is a Column?

A column represents an attribute or field in a table.

5. What is a Primary Key?

A primary key uniquely identifies each row in a table.

6. Can a Primary Key contain duplicate values?

No.

7. Can a Primary Key contain NULL values?

No.

8. What is SELECT?

SELECT is used to retrieve data from a table.

Example:

SELECT * FROM Employee;

9. What is WHERE?

WHERE is used to filter records.

Example:

SELECT *
FROM Employee
WHERE salary > 50000;

10. What is AND?

AND is used when multiple conditions must be true.

Example:

WHERE salary > 50000
AND department = 'IT';
